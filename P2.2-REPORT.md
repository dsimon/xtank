## Schema summary

- **Envelope** (`Protocol/limits.h` `XTK_ENVELOPE_BYTES` = 32): magic
  `0x58544B31`, major 1 / minor 0, type, channel, u32 payload length, session
  id, epoch, message sequence, i32 tick, reserved. Big-endian, packed, no native
  struct. Ordered validation: magic → exact version → length → channel →
  reserved → non-negative tick.
- **Channels:** 0 reliable ordered (control, events, acks, errors, reliable
  edge commands); 1 unreliable sequenced (self-contained `VIEW_SNAPSHOT`); 2
  unreliable sequenced (`INPUT_BATCH`).
- **Message types:** 0x01–0x05 handshake/ping; 0x10–0x18 catalog/config/
  ready/start/epoch/results/reset/quit; 0x20–0x23 event/ack/protocol-error/
  reliable-cmd; 0x40 snapshot; 0x60 input batch.
- **Ops:** `DRIVE_REL`, `DRIVE_ABS`, `HEADING`, `FIRE`, `WEAPON`, `AIM_WORLD`,
  `FIRE_HOLD` release-authorized; `AIM_TARGET`/`CHASE`/`STANDOFF` test-only;
  `HEARTBEAT`. Explicit `a`/`b` ranges; NaN/±Inf rejected.
- **Field authorization:** `SELF` (own armor/fuel/heat/ammo/weapon/score),
  `VISIBLE` (vehicle/bullet/explosion/landmark visual state in the reference
  viewport), `MAP` (mapper knowledge cells, never full `real_map`), `RADAR`
  (blip position/age/classification), `PUBLIC` (results). P2.5 narrows, never
  widens, these.
- **Content identity:** stable IDs `0x0101` combat1, `0x0102` Arena, `0x0201`
  Vanguard; pinned SHA-256 of the exact supplied bytes, the canonical release
  preset and the frozen geometry table; `content_set_digest` exchanged in
  HELLO/CONTENT_CATALOG. Mismatch fails before start, no auto-download.
- **Scheduling:** bounded pre-step admission; commands assigned to the next
  unconsumed tick in order; `tick_hint` is only a freshness hint; per-command
  `(command_id, assigned_tick, status, reason)` acks; cross-channel dedup;
  stale/prior-generation reliable edges rejected rather than fired.
- **Results:** captured while scores exist, reliable, retained until RESET.
- **Wrap/reset:** session/epoch/message/packet/command/event/snapshot sequence
  rules in §12 of the doc; engine `tick` stays signed `i32`, epochs end before
  overflow; client clears the 8-entry ring and 256 pending events on epoch
  change.

bullets (16 352) + 255×24 explosions (6 120) + 900×4 map cells (3 600) + 50×24

single application message; reliable output stays bounded at 256 KiB/peer.

## Deferred / open

- **Owner protocol approval** of `docs/PROTOCOL-v1.md` is the outstanding
  acceptance item; the schema is frozen for review, not yet signed off.
- **Codec** (encode/decode, sanitizer/fuzz) is P2.3; it must reproduce the
  golden bytes. This task intentionally ships no encoder.
- **View/visibility semantics** (reference viewport, occlusion, death camera)
  are derived from legacy evidence in P2.5 (`docs/VIEW-v1.md`); P2.2 fixes the
  wire fields and authorization classes only.
- **Complete `init_settings()` table hash** is not in v1; the approved release
  override set + special preset are pinned via `release-preset.txt`. Widening
  this changes the content identity and is a synchronized content-version event.
- **ENet fragmentation behavior** for the maximum snapshot must be verified in
  P2.7; if unreliable fragmentation proves unsafe, atomic reassembly or a
  revised bound requires owner approval before proceeding (§6 stop condition).
