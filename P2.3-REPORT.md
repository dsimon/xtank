## Codec summary

- **Encode** (`xtk_encode`): writes the 32-octet envelope, computes
  `payload_length`, forces magic/version/channel/reserved, serializes the typed
  body, and rejects unknown types, over-bound counts, malformed strings and
  non-finite `f64`. Fixed-width integers and `f64` bits are written
  big-endian by explicit shifts, so host byte order cannot change an octet.
- **Decode** (`xtk_decode`): validates in the schema order — magic → exact
  major/minor version → declared-length bound and consistency with the buffer →
  known type → channel match → zero reserved → non-negative `tick` — then
  parses the body bounds-checked, rejecting over-bound counts before use,
  length-prefixed/non-ASCII strings, NaN/Inf `f64` and any trailing or truncated
  octet (exact payload consumption). Errors are the frozen `XTK_ERR_*` codes.
- **Messages covered:** all 20 `XtkMessageType` values (PING/PONG, HELLO, WELCOME, REJECT,
  CONTENT_CATALOG, CONFIG_SELECT, CONFIG_STATUS, READY, START, EPOCH_BEGIN,
  RESULTS, RESET, QUIT, EVENT, CMD_ACK, PROTOCOL_ERROR, RELIABLE_CMD,
  INPUT_BATCH, VIEW_SNAPSHOT). `sizeof(XtkMessage)` = 35 208 bytes.
- Op-range and ownership/sequence authorization are deliberately **not** in the
  codec; they are admission policy for P2.7.

## Rejection results (all asserted to a specific error)

- **Truncation at every field:** every raw prefix `0..len−1` of every fixture is
  rejected; additionally each prefix `32..len−1` with a matching declared
  `payload_length` is rejected by the inner field readers.
- **Oversized counts:** INPUT_BATCH/RELIABLE_CMD/CMD_ACK command counts,
  CATALOG entries, RESULTS vehicles, VIEW_SNAPSHOT vehicle count, HELLO name
  length → `XTK_ERR_BAD_LENGTH` / `XTK_ERR_MALFORMED`.
- **Unsupported type / version:** unknown message type → `XTK_ERR_BAD_TYPE`;
  wrong major → `XTK_ERR_BAD_VERSION`; wrong minor → `XTK_ERR_VERSION_MISMATCH`.
- **Envelope:** bad magic, wrong channel, non-zero reserved, negative tick,
  `payload_length` wrap (`0xFFFFFFFF`), inconsistent length, trailing octet.
- **NaN/Inf:** NaN and +Inf in an INPUT_BATCH operand → `XTK_ERR_NONFINITE`
  (decode); the encoder also rejects NaN operands.
- **Malformed strings:** over-long `name_len` and a non-ASCII string byte.
- **Cross-endian / wrap:** primitives asserted big-endian; `i32 −2` asserted as
  two's-complement wrap.

## Deferred / notes

- **Native Windows execution** of the codec is P2.9's runtime proof (per the
  P2.3 dependency note). This task executes the MinGW-built binary here under
  Wine; that runner is a convenience, not the Phase 2 exit evidence.
- **Owner protocol approval** of `docs/PROTOCOL-v1.md` remains the outstanding
  P2.2 acceptance item.
- **Op-range, ownership, dedup/expiry and scheduling authorization** are P2.7
  (admission), not codec responsibilities; the codec rejects only structural
  and finiteness violations.
- **Wine environment quirk (recorded, not a code defect):** in this sandbox Wine
  aborts with a glibc heap error if the `TMPDIR` environment variable is set;
  `codec.sh` unsets `TMPDIR` for the Wine invocation only.
