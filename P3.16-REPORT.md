## Findings

- **F1 (fixed, build portability).** Required MinGW-w64 cross-build of the
  shipped client failed: `Transport/enet_transport.c` called `clock_gettime()`,
  absent in the pinned **win32-thread** MinGW model without libwinpthread
  (forbidden by D2-D). Minimal reviewed fix: `tx_now_ns()` uses
  `QueryPerformanceCounter` under `_WIN32`.
- **F2 (reconciled, inherited Phase 2).** The P3.3 exact-version-1.1 bump
  supersedes the v1.0 byte-golden Phase 2 drivers. The gate runs the still-valid
  drivers, records each superseded driver with its required Phase 3 successor,
  and `require_successors` fails if any successor is not PASS. Nothing is
  silently dropped; v1.0 fixtures remain independently verified (P3.3).
- **F3 (host prerequisites, installed).** Fresh VM lacked `flex`, `xdpyinfo`,
  `xrdb`, MinGW-w64. Installed and added to the gate's prerequisite check, so a
  missing tool BLOCKS rather than PASSes.
