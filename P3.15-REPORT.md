## What was built (new files, harness only)

- `Tests/phase3/soak_fixture.c` — one continuous, absolute-deadline-paced
  (15 Hz) two-human / two-drone match driven through the shipped coordinator +
  admission + pinned ENet v1.3.18 transport + frozen v1 codec + two real P3.10
  client sessions (direct loopback). Every ~180 s a single RESET returns to the
  shared lobby and a fresh ready/start begins the next epoch; on four selected
  cycles a mid-epoch admin departure (2 s valid-input removal + administrator
  transfer) is exercised and the departed client **rejoins with a fresh
  connection/ownership**. Progress is written incrementally (fflushed) so the
  run survives an agent-session death.
- `Tests/phase3/soak.sh` — build / run / analyze / status driver; `--stage run`
  is launched detached (`setsid nohup … < /dev/null &`).
- `Tests/phase3/soak-analyze.py` — machine-readable verdict over the
  incremental evidence against the P3.15 acceptance criteria.
