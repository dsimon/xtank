## G before/after — byte-identical

Because Phase 1 is uncommitted, `regression.sh --stage before` — which snapshots
`git archive HEAD` — resolves to the pre-implementation plan tree, which cannot
build `-DNULL_BACKEND` (no `graphics_backend.h`). This is a repo-state property,
not a simulation difference, and matches the plan's warning. The pre-change
baseline was therefore taken with `--stage after` on the unmodified working
tree, which is the same candidate `make phase1-check` evaluates:

- before: the oracle inside the `phase1-check` run above
